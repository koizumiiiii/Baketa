利用規約

この利用規約（以下「本規約」）は、Baketa（以下「本サービス」）の利用条件を定めるものです。ユーザーの皆様（以下「ユーザー」）には、本規約に従って本サービスをご利用いただきます。

第1条（適用）

本規約は、ユーザーと本サービス運営者との間の本サービスの利用に関わる一切の関係に適用されるものとします。

第2条（アカウント・有料サービスの終了）

  1. 最終版では、ログイン・アカウント・有料プラン（Patreon）・プロモーションコード・Baketa提供のCloud AI翻訳を廃止します。
  2. 旧Relay Serverとアカウント機能は2026-11-29に停止予定です。その後、Supabase上のアカウント情報・利用ログ・クラッシュレポート、およびCloudflare KVのセッション情報を削除し、2026-12-13までの完了を目標とします。この削除予定は従来の保持期間に代わるものです。それ以前の削除請求はprivacy@baketa.appで受け付けます。

第3条（翻訳と利用者自身のAPIキー）

  1. ローカルNLLB-200翻訳は引き続き無料です。自分のAPIキーでGeminiまたはGoogle Cloud Translationも利用できます。第三者サービスの利用は利用者の責任となり、API利用料は利用者とGoogleの契約によります。
  2. 自分のAPIキーでGeminiを選択すると、画面のキャプチャ画像をGoogleへ直接送信します。Google Cloud Translationでは、OCRで抽出したテキストをGoogleへ直接送信します。Googleの規約・プライバシーポリシーが適用されます。Gemini APIの無料枠では、Googleが送信データを製品改善に利用する場合があります。機密情報を送信する前にGoogleの条件をご確認ください。翻訳は自動生成され、正確性は保証されません。 Gemini API · Google Cloud Translation · Googleのプライバシーポリシー
  3. APIキーはWindows DPAPIで暗号化してPC内に保存します。API利用時にGoogleへ送信しますが、Baketaの運営者には送信しません。APIキーの管理は利用者の責任で行ってください。
