プライバシーポリシー

Baketaの開発は終了しました。v1.0.0を最終版として公開しました。今後のアップデート・保守・サポートは行いません。ソースコードはGitHubで公開を続けます。

1. 最終版について

最終版では、ログイン・アカウント・有料プラン（Patreon）・プロモーションコード・Baketa提供のCloud AI翻訳を廃止します。

2. ローカル処理

OCRとローカルNLLB-200翻訳はPC内で処理され、初回セットアップ後はオフラインで利用できます。最終版はBaketaのサーバー（Relay Server / Supabase）と通信せず、使用統計やクラッシュレポートも送信しません。最終版アプリの利用によりBaketaの運営者が取得・保存するデータはありません。

3. Google APIの利用

自分のAPIキーでGeminiを選択すると、画面のキャプチャ画像をGoogleへ直接送信します。Google Cloud Translationでは、OCRで抽出したテキストをGoogleへ直接送信します。Googleの規約・プライバシーポリシーが適用されます。Gemini APIの無料枠では、Googleが送信データを製品改善に利用する場合があります。機密情報を送信する前にGoogleの条件をご確認ください。翻訳は自動生成され、正確性は保証されません。 Gemini API · Google Cloud Translation · Googleのプライバシーポリシー

4. APIキーの保存

APIキーはWindows DPAPIで暗号化してPC内に保存します。API利用時にGoogleへ送信しますが、Baketaの運営者には送信しません。APIキーの管理は利用者の責任で行ってください。

5. コンポーネントの取得

初回のコンポーネント取得にはインターネット接続が必要です。GitHub Releases、HuggingFaceのtokenizer、models.datalab.toのSurya OCRモデルを取得します。取得先にはダウンロード要求が届き、各提供者のポリシーが適用されます。セットアップ後のアプリの外部通信は、利用者が選択した場合のGoogle APIに限られます。

6. ユーザーの権利

ユーザーは、自身の個人情報について以下の権利を有します：

  • アクセス権：保有する個人情報の開示を請求できます
  • 訂正権：不正確な情報の訂正を請求できます
  • 削除権：アカウントおよび関連データの削除を請求できます
  • データポータビリティ：一定の条件下でデータの提供を請求できます

これらの権利を行使する場合は、下記のお問い合わせ先までご連絡ください。

CCPA対応（カリフォルニア州消費者プライバシー法）：当社はユーザーの個人情報を第三者に販売しません。また、ターゲティング広告やクロスコンテキスト行動広告の目的で個人情報を共有することもありません。

7. 未成年者のプライバシー

本サービスは、16歳未満の方を対象としていません。16歳未満の方が個人情報を提供されたことが判明した場合、当社は速やかにその情報を削除します。

8. 旧サービスのデータと削除

旧Relay Serverとアカウント機能は2026-11-29に停止予定です。その後、Supabase上のアカウント情報・利用ログ・クラッシュレポート、およびCloudflare KVのセッション情報を削除し、2026-12-13までの完了を目標とします。この削除予定は従来の保持期間に代わるものです。それ以前の削除請求はprivacy@baketa.appで受け付けます。

最終版の初回起動時に、旧版がPC内に保存したログイン情報・ライセンス情報を削除します。削除に失敗した場合は次回以降の起動時に再試行します。このローカル削除と、旧サーバー上のデータ削除は別の処理です。

9. ウェブサイトのアクセス解析

baketa.appのランディングページでは、アクセスや操作の分析にGoogle Analyticsを使用し、Cookieを使用する場合があります。これは最終版アプリとは別のウェブサイト上の処理です。ブラウザーでCookieを制限できます。Google AnalyticsにはGoogleのプライバシーポリシーが適用されます。

10. ポリシーの変更

本ポリシーの変更やサービス終了に関するお知らせは、このウェブサイトに掲載します。

11. お問い合わせ

プライバシーに関するお問い合わせ・データ削除請求は、引き続きprivacy@baketa.appで受け付けます。製品サポートは終了しています。
